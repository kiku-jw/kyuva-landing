## One-sentence description

Kyuva is a free local-first Mac teleprompter that keeps scripts beside the
camera with speed, WPM, or finish-time pacing and no account or cloud upload.

## Community draft

I made a small free Mac teleprompter for calls, demos, lessons, and prepared
talks. It stores scripts locally and is distributed through the Mac App Store.
The overlay is a normal window, so I do not claim that it is hidden from screen
sharing—check the preview first. I also published a plain-text 60–90 second
product-demo script template. If this matches your workflow, I would value
feedback on pacing and readability rather than feature requests in the abstract.

## Directory description

Free open-source teleprompter for macOS 13 or later. Kyuva keeps a compact
always-on-top script near the camera, supports fixed speed, WPM, and target-time
pacing, and stores scripts locally. No account, subscription, advertising,
analytics, or required cloud service. The window may appear in captures.

## Editor pitch

Kyuva is relevant to a “free Mac teleprompter” list when the selection criteria
include App Store installation, local script storage, Intel and Apple silicon
support, and honest capture limits. Public source, release facts, and a reusable
product-demo template are available for verification. No ranking, review, or
link placement is requested without editorial testing.
